# Bulkify

Bulkify by Nettax ( Radhe Solution ).

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/bulkify/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Bulkify** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/bulkify/releases/latest) and reinstall.
